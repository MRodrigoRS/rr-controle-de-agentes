### Como adicionar uma nova tecnologia

Edite o arquivo `tecnologias.json` na progenitora seguindo o formato:

```json
{"nome": "Tecnologia", "categoria": "Categoria", "ranking": 1, "aplicabilidade": "...", "descricao": "..."}
```

Consulte a skill `alinhar-stack-com-presets.md` para instruções de como contribuir com novas tecnologias.
