---

### Como cadastrar uma nova tecnologia no catálogo

Execute o comando atômico no terminal da progenitora:

```bash
npm run rr:tecnologia -- --nome "Nome" --categoria "Categoria" --aplicabilidade "..." --descricao "..."
```

O banco SQLite atribuirá um ID numérico auto-incremental imediatamente e sincronizará o catálogo.
