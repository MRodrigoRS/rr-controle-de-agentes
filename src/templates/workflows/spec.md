# Workflow: Spec

> Transforma uma ideia/visão em especificação orientada a requisitos antes de
> planejar. Alimenta o [PRD.md](governanca/PRD.md).

## Quando Usar

- Antes de uma mudança significativa
- Quando o requisito é vago e precisa de clarificação

## Passos

1. Responda: o que estamos construindo? Para quem? Qual problema resolve?
2. Delimite: o que está dentro e fora do escopo
3. Liste requisitos e critérios de aceite **verificáveis** (não "login funcionando")
4. Aponte restrições e riscos
5. Valide com o usuário antes de planejar

## Saída

Atualização de [PRD.md](governanca/PRD.md) com os critérios de aceite e o escopo.

## Critérios de Conclusão

- Critérios de aceite são verificáveis (dá para saber quando terminou)
- Usuário aprovou a especificação
